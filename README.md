# 👕 TrendWear – Men's T-Shirt Store 🛍️

✨ A modern and responsive *Men's T-Shirt E-Commerce Website* built using *React.js*.

TrendWear provides a simple and attractive shopping experience where users can browse different T-shirts, filter products by category, add products to the cart, and manage their cart items easily. 🛒💙

---

## 🚀 Features

✨ *Modern & Responsive UI*  
👕 Browse different T-Shirt collections  
🖨️ Printed T-Shirts category  
🏏 Sports T-Shirts category  
🔥 Special Offers section  
🛒 Add products to cart  
➕ Increase product quantity  
➖ Decrease product quantity  
🗑️ Remove products from cart  
🧹 Clear entire cart  
📋 Order Summary  
💰 Dynamic total price calculation  
🔢 Dynamic cart item count  
🧭 React Router navigation
